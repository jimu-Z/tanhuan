# 学生谈心谈话系统 — 领域术语

## 角色

- **辅导员（Counselor）**：一线谈话执行者，负责大批量日常谈话发起与记录，关心"今天要跟谁谈、还有谁没谈"
- **书记（Secretary）**：全局管理者，具有完整 CRUD 权限（含新增/修改/删除），关注统计数据、谈话覆盖率与学生管理
- **管理员（Admin）**：系统运维角色，管理基础数据导入、系统配置，具有标签管理与系统配置的独占权限
- **学生（Student）**：谈话对象，通过独立学生端登录（学号+初始密码123456），可查看自己的谈话记录、填写反馈，收到新谈话通知

## 首页

- 首页按角色差异化展示：辅导员看到面向执行的工作台，书记看到面向统计与管理的仪表盘
- 管理员默认等同于书记视角
- 辅导员首页卡片：发起谈话、我的记录、学生管理、预警提醒、谈话模板库、谈话跟进
- 书记首页卡片：学生信息管理、发起谈话、统计分析、预警提醒、数据大屏、统一查询
- 学生首页：我的谈话记录、待处理谈话、个人中心

## 班级层级

- 班级通过 `sys_dept` 树表示，层级为 **学院 → 年级 → 班级**，学生挂在班级叶子节点下
- 选择学生时通过班级树导航，支持按班级批量选择（一键全选某班学生参加集体谈话）

## 谈话附件

- 一次谈话可附带多个附件文件（图片、PDF、Word 等），作为独立附件上传区，不嵌入谈话内容
- 附件表单独存储（`talk_attachment`），不限制单个文件大小

## 谈话标签

- 标签为系统全局定义，存储于 `talk_tag` 表，由管理员独占管理（新增、编辑、停用、逻辑删除）
- 停用或逻辑删除的标签不再出现在新建谈话的选择列表中，但历史已使用的标签数据保留不变
- 现有硬编码常量（`TalkConstants.TAG_LABELS`）将被替换为数据库驱动的标签读取

## 谈话通知

- **学生通知**：老师发起/编辑谈话后，学生端看到待处理谈话 + 顶栏红点通知
- **教师通知**：学生提交反馈后，教师端仪表盘显示"待查看反馈"数量
- 通知机制基于 `talk_student_record` 的标记字段简化实现（`notified` / `teacher_notified`），不建立独立通知表

## 学生端

- 学生端为独立 Vue2 + Element UI 前端项目，复用后端 API
- 学生账号在 Excel 导入时自动创建（登录名=学号，初始密码=123456），所有学生均可登录
- 学生端功能：我的谈话记录、待处理谈话（在线填写反馈）、个人中心（修改密码）
- 学生不能查看同次集体谈话中其他参与者的信息

## 集体谈话

- 集体谈话参与学生信息在三个位置展示：会话管理列表（缩略）、会话详情页（完整）、docx 导出（汇总表）
- docx 导出分为两种：每人一份独立记录（保留），集体谈话汇总表（新增，模板后续提供）
- 导出时附件不嵌入 docx

## 未谈学生筛选

- 在"统一查询"页面新增查询模式切换：查已有记录 / 查未谈学生
- 查未谈学生：选择班级 + 日期范围，列出该时间段内无任何谈话记录的学生名单
- 支持按班级维度快速查看已谈/未谈覆盖率
