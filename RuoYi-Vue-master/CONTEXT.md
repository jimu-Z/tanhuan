# 学生谈心谈话系统 — 领域术语

## 角色

- **辅导员（Counselor）**：一线谈话执行者，负责大批量日常谈话发起与记录，关心"今天要跟谁谈、还有谁没谈"
- **书记（Secretary）**：全局管理者，具有完整 CRUD 权限（含新增/修改/删除），关注统计数据、谈话覆盖率与学生管理
- **管理员（Admin）**：系统运维角色，管理基础数据导入、系统配置

## 首页

- 首页按角色差异化展示：辅导员看到面向执行的工作台，书记看到面向统计与管理的仪表盘
- 管理员默认等同于书记视角
- 辅导员首页卡片：发起谈话、我的记录、学生管理、预警提醒、谈话模板库、会话管理
- 书记首页卡片：学生信息管理、发起谈话、统计分析、预警提醒、数据大屏、统一查询
