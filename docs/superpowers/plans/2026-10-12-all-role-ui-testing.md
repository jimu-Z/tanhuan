# 全角色按钮与表单测试计划

1. 在已有隔离数据库和当前源码开发界面上测试，不重建旧 QA 数据。
2. 对四角色实际菜单建立页面与按钮矩阵，包含查询、重置、增改删、导入导出、详情、弹窗提交/取消、分页、公共导航、个人中心及实际可见系统管理菜单。
3. 每个表单对照 CONTEXT.md 与用户既定要求检查字段、角色、备注、必填、中文、联动和数据范围。
4. 逐项浏览器操作记录结果；权限隐藏记录依据，异常输入与正常提交分别验证。
5. 修复复现问题，保留修复前证据，运行必要回归并从浏览器复测。
6. 审计所有矩阵项，生成报告。尚未实测项不得标通过，未完成不得宣布完成。

7. 用户于2026-10-13取消关机安排：不自动退出程序、网络代理或关闭电脑。全角色按钮测试、修复、报告继续；用户取消测试或全部测试及报告完成后暂停自动跟进。
